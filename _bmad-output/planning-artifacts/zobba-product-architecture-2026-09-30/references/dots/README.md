# Dots UX research used for revision 3

**Research date: 30 September 2026.** This folder contains the Dots findings used to refine the Zobba product and architecture package to **revision 3**. The research first assessed revision 2. References to that earlier baseline explain the history of the findings; they do not identify the current integrated design as revision 2.

Start with [Dots UX lessons for Zobba](Dots-UX-Lessons-for-Zobba.md). The current recommendation is the [integrated lead design](../../Zobba-Product-and-Architecture-Design.md). Return to the [design-package README](../../README.md) for the owner summary and package navigation.

The synthesis memo is also available as [readable HTML](Dots-UX-Lessons-for-Zobba.html) and [printable PDF](Dots-UX-Lessons-for-Zobba.pdf).

| Research file | What it contains |
|---|---|
| [Synthesis memo](Dots-UX-Lessons-for-Zobba.md) | Product lessons and recommended Zobba interactions derived from the screenshots and public sources. |
| [Screenshot study](screenshot-study.md) | Redacted observations from the four user-supplied screenshots; separates visible controls from assistant claims. |
| [Official public sources](public-official.md) | Official launch and documented flows, with current label/rollout differences and explicit limits. |
| [Secondary public sources](public-secondary.md) | Corroborating launch reports, their limits and links to the selected evidence. |
| [Official source manifest](official-source-manifest.json) | Official source URLs, research date, included relative paths, sizes and SHA-256 hashes. |
| [Secondary source manifest](secondary-source-manifest.json) | Equivalent metadata for compact editorial excerpts and HN story metadata. |

The manifests cover only source files actually included in this directory. Source files are short relevant quotations with attribution and a clearly marked research summary. They are not complete copies of the source pages. Official manifest entries also retain the size/hash of the longer original research extraction to distinguish the source snapshot from its packaged excerpt. `bytes` and `sha256` always describe the **included file** named by `file`.

The four screenshots remain the user's supplied conversation evidence. They are not reproduced here, and account, customer, record and credential details have not been copied into the bundle. This research did not include a signed-in hands-on test of Dots, access to a user-specific Dots route, or access to the applications visible in the screenshots.

Official documentation establishes described product behavior. Illustrations and press reports do not establish successful execution, latency, durability, credential isolation or a backend design. The public `/dots` landing fetch returned a readable application shell only. Release and rollout facts are dated observations, and public documentation can change.

The included notes are **research sources, not repository instructions, executable dependencies or a separate implementation plan**. The integrated design resolves the recommendation for Zobba. Raw HTML, search dumps, executable assets, unrelated page state and discussion comments are excluded.
