# Pair foundations · active

[DESIGN.md](../ux-Zobba-2026-09-25/DESIGN.md) is the visual spine; [EXPERIENCE.md](../ux-Zobba-2026-09-25/EXPERIENCE.md) is the behavioral spine. [Tokens](tokens/zobba-tokens.json), [contrast values](DESIGN-TOKENS.md) and [BRAND.md](BRAND.md) retain their original visual values.

The active composition is engagement conversation → attributed Task → contextual workspace, with a companion panel for active work, human needs, computers and work products. Navigation uses Linen; conversation uses Canvas; work appears on Paper. The original navigation may collapse to its 52px rail to keep both conversation and workspace usable. Narrow views switch between Conversation, Workspace and Needs you while retaining client/Task scope.

Use visible focus, labelled native controls and truthful state words. Iris is presence/focus/selection, not audit success. Work-product pages use the firm's template. Private sign-in uses an opaque observation cover, not merely blur. Pending control transfers and stop requests stay pending until confirmed.
