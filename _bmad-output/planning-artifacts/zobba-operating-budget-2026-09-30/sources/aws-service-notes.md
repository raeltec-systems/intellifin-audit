# AWS pricing and compatibility notes

Checked 30 September 2026. This file records bounded facts, not a full copy of the pages. All scenario quantities are budget assumptions.

- [AWS support pricing](https://aws.amazon.com/premiumsupport/pricing/): current **Business Support+** minimum $29/account/month, or 9% of first $10,000 usage, 7% next $70,000, 5% next $170,000, 3% thereafter, whichever is greater. The older `AWSSupportBusiness` offer catalogue still describes old Business $100/10%; this budget deliberately uses the current named plan, not that older SKU. Production account enrolled; separate nonproduction account stays on included Basic Support. Confirm the selected account plan before purchase.
- [RDS supported instance classes](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Concepts.DBInstanceClass.Support.html): db.m9g.large row explicitly lists PostgreSQL 18.1 and higher. Price List product attributes specify 2 vCPU / 8 GiB and Multi-AZ $0.366/hour, Single-AZ $0.183/hour in us-east-1. That is the ordinary primary/standby deployment, not the three-node readable-standby cluster. Older m7g/t4g rows did not explicitly list 18 at inspection, so their lower rates are not the selected baseline. Confirm orderability of the exact engine minor/version in the deployment account; no account API was called.
- [RDS PostgreSQL pricing](https://aws.amazon.com/rds/postgresql/pricing/): backup storage up to 100% of provisioned database storage in the region is included in the service; excess is $0.095/GB-month. This is a built-in backup allowance, not an assumed promotional credit. The worksheet budgets excess backup separately. Multi-AZ storage $0.23/GB-month already includes its paired deployment; do not multiply it or compute price by two again.
- [AWS VPC pricing](https://aws.amazon.com/vpc/pricing/): S3 gateway endpoints have no hourly/data processing fee. ECR API/DKR and CloudWatch Logs interface endpoints are explicitly counted for the isolated analysis network. Ordinary API/KMS/Secrets traffic uses the already-counted NAT gateways.
- [AWS Fargate pricing](https://aws.amazon.com/fargate/pricing/): Linux x86 per-vCPU and per-GB-memory allocation is billed for task duration; 20 GiB ephemeral storage is included. No Savings Plans, Spot or free credits are assumed.
- [Amazon CloudTrail pricing](https://aws.amazon.com/cloudtrail/pricing/): first trail copy of management events is included; data events cost $0.10/100,000. Storage/request costs remain. No CloudTrail Lake, Insights or duplicate paid management trail is enabled in this configuration.

The whole operating budget uses gross paid rates for Cognito, KMS, CloudWatch, data egress and CodeBuild, without subtracting account-level free tiers. TLS through an integrated ACM-issued public certificate and ordinary S3 gateway endpoints incur no separate certificate/endpoint fee. Optional advanced security, cross-region replication and a second disaster-recovery region are not silently enabled.
