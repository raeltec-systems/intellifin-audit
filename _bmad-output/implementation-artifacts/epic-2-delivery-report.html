Important decisions and lessons

  • Your handover decision is recorded. Approval of a successor that needs regression testing records its pending regression and predecessor relationship. Its authoritative handover date is set only when regression passes and it activates; no speculative date is shown at approval. The architecture and story contracts now agree on this timing.
  • Derivation survives interrupted work. An audited start is stored before model work. Bounded retry and recovery retain unfinished attempts, preserve successful plans and detect older-process saves. The preview identifies the attempt that produced the current stored plan.
  • Models cannot silently change executable meaning. Both installed provider SDKs are tested with synthetic HTTP. Their complete response must match the frozen contract; canonical compiler bytes are stored. A live provider acceptance check still needs a deployment credential.
  • Native PostgreSQL removed the Docker blocker. Docker Desktop failed during startup. Verification now uses an isolated native PostgreSQL 18.6 test cluster with TLS and password authentication. No application database was used.
  • Concurrency protects the values as well as the save token. A refreshed token must not give stale local values permission to overwrite another auditor’s section. Delayed save responses also need to preserve newly detected conflicts.
  • Capture follows saved targets. Mandatory Structural Snapshot and screenshot requirements are derived from current Target selections, including during upgrades. Grounding validation runs after this authoritative derivation.
  • A lost response is not proof of a failed save. The editor must ask the Auditor to reload and inspect the saved state rather than claim that nothing changed.
  • Development logs must not expose action arguments. Next’s Server Action argument logging was disabled after verification showed it could include submitted credentials. A further browser check confirmed that account creation still worked without those argument traces.

Reusable details are recorded in CLAUDE.md. The final report will include the remaining stories’ decisions and verification evidence.
