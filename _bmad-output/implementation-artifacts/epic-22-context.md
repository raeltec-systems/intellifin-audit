# Epic 22 Context: Let Zobba investigate and analyse within the brief

## Goal

Enable continuing Tasks to reason through native model providers, use admitted tools and firm techniques, and analyse selected material in isolation. Useful work must remain attributable, bounded and steerable through changed guidance, interruption and access changes. A successful model response is neither completed audit work nor authority to act.

## Stories

- Story 22.1: Route native models through a current tool catalog
- Story 22.2: Continue a real Task under changing guidance
- Story 22.3: Compact context without inventing authority or evidence
- Story 22.4: Run measured analysis in an isolated workspace
- Story 22.5: Extract usable facts with stable source locations
- Story 22.6: Use methods and installed skills during investigation
- Story 22.7: Keep work within budgets and responsive under contention

## Requirements & Constraints

Every invocation identifies Task/cycle/attempt, producing intent revision, requested and actual provider/model, effort, capability profile, input classes, context manifest, tool-catalog revision, destination and usage. Automatic routing stays within an Admin-approved profile; auditors can inspect permitted choices. Unsupported capability or destination changes are explicit, never silent fallback. Complete arguments must pass size, schema and semantic validation before becoming a tool proposal eligible for admission.

Current authority intersects organisation, engagement, member, accepted Task, account, resource, purpose and delegation. Model output, retrieved instructions, skill text and MCP annotations cannot grant authority. Recheck permitted disclosure immediately before outbound requests and before late results enter viewers, context or work products. Restrict dependent summaries, previews and provider continuations after revocation. Secrets never enter model context, browser clients, ordinary telemetry or analysis programs.

Persist messages before interpretation and distinguish discussion, new objectives, guidance and controls. Resolve material targeting ambiguity before action. A first objective may establish an engagement conversationally: resolve the authorised client and period and establish scope and assignment before acquiring material. Do not require a procedure or skill-selection wizard. Missing criteria block dependent evaluation, not independent permitted discovery. Accepted guidance and its actual application remain separate facts; stale proposals cannot contradict applied guidance.

Native adapter fixtures cover malformed/partial streams, timeouts, hostile results, unsupported capabilities and safe retries. Live minimal qualification requires both native providers with approved credentials and spend ceilings. Fixtures do not establish live qualification. Actual isolated-job and real-computer qualification similarly require their specific environments and permissions. Current authorization does not approve live model calls, Graph access, hosting, deployment or the proposed region/spend ceiling.

## Technical Decisions

Use one Rust application authority with a fresh PostgreSQL schema and React/TypeScript Pair UI. Domain and application ports own meaning; provider, HTTP, SQL and cloud wire types stay in infrastructure. Native OpenAI Responses and Anthropic Messages implement a portable request/event representation without a shared imitation provider protocol, Codex subprocess authority or SDK-owned execution loop.

Streams distinguish text, complete tool proposals, structured answers, refusals, usage, completion and classified errors. Preserve identifiable partial output without executing it. Canonical tool descriptors bind identity/version, schemas, account/resource, purpose, effect class, limits, output completeness, cancellation, idempotency and reconciliation. Reject normalized name collisions and effective-parameter substitution. API, vetted MCP and computer routes share admission semantics.

Durable Task commands, owner/intent/execution epochs, operations, attempts and one-use claims govern work. Record admitted operations before dispatch; recheck authority at claim consumption. Contradictory old-intent proposals require rejection or rebasing even when the owner epoch is still valid. Applying guidance fences conflicting unused claims; consumed claims remain possibly dispatched until reconciled. Provider switching occurs between committed cycles from portable history without replaying effects. Optional continuation tokens bind exact Task/model/context/permission state and can always be discarded.

Assemble enforced constraints, bound methodology and necessary skills, objective/decisions, unresolved work, recent conversation, authorised knowledge and selected evidence before optional advice. Bound text, images, tool descriptors and output independently. Compaction retains source/version/scope dependencies, covered events, limitations and omissions; reconstruct exact decisions and unresolved effects from durable records. Filter access and applicability before retrieval ranking. Missing or partial retrieval never proves absence.

Run selected immutable files in bounded disposable Fargate analysis jobs with versioned programs/environments, no general egress and no credential-bearing task role. External trusted staging and collection provide scoped handles; a privileged sidecar is not isolation. Verify whole-job termination and validate paths, links, types, sizes and hashes before descendant registration. Preserve original bytes, extraction versions, stable page/cell/message locators and uncertainty. No macros or fabricated output after limits or parsing failure.

Reserve budgets before paid work; bound organisation/Task/provider/analysis capacity and bytes separately. Fair queues and reserved control capacity keep guidance and Pause/Stop independent of stalled calls. Human/evidence waits release compute; uncertain charges retain reservations until reconciled or explicitly estimated. Settlement is attributable and deduplicated, with customer consumption separate from shared overhead.

## UX & Interaction Patterns

Keep the engagement conversation usable while distinct Task cards show objective, current work, method, next action, attention and outputs. Expose the revisable Working brief and what Zobba is using. Controls name their Task and delegated scope; Pausing/Stopping remain pending until observed quiescence or an explicit unresolved condition. Other Tasks continue. Stop preserves history and a later continuation creates a new work cycle.

Preserve pinned inspection, selection and keyboard focus; following resumes only explicitly. Display partial output, gaps, budget/capacity waits and usable recovery actions without invented progress. Narrow views retain scoped controls and a return to conversation. Use Pair assets and WCAG 2.2 AA interactions. Methods remain versioned Admin configuration through ordinary validated Save; imported interpretation is a proposal, not an effective method or approval ceremony.
